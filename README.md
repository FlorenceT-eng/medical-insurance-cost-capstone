# Medical Insurance Cost Capstone

## Project Description
This project predicts individual medical insurance charges using regression models.

This is TechCrush Cohort 9 Data Science Capstone, Group 2, Case 1.

## Problem Statement
Medical insurance charges vary based on age, sex, BMI, children, smoker status, and region. This project builds models to predict charges accurately.

## Dataset
Medical Cost Personal Dataset with features: age, sex, bmi, children, smoker, region, charges.

## Tools Used
Python, Pandas, Numpy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## Models Used
- Linear Regression
- Random Forest Regressor
- Gradient Boosting

## How to Run
1. Clone the repo
2. Open the notebook
3. Run all cells
